# Requisitos Funcionais

## Tabela 1 — Requisitos Funcionais da Página Home

| ID | Requisito | Prioridade |
|----|-----------|------------|
| RF01 | O sistema deve exibir a aba de início na navegação lateral. | Alta |
| RF02 | O sistema deve permitir acesso à seção “Minhas Cartas”. | Alta |
| RF03 | O sistema deve permitir acesso à seção “Coleções”. | Alta |
| RF04 | O sistema deve permitir acesso à seção “Favoritos”. | Média |
| RF05 | O sistema deve permitir criar novas cartas pela página inicial. | Alta |
| RF06 | O sistema deve exibir as cartas recentes do usuário na página inicial. | Alta |
| RF07 | O sistema deve permitir a busca de cartas pela barra de pesquisa. | Alta |

*Tabela 1:* Requisitos Funcionais da Página Home.

---

## Tabela 2 — Requisitos Funcionais da Criação de Cartas

| ID | Requisito | Prioridade |
|----|-----------|------------|
| RF08 | O sistema deve disponibilizar uma área para visualização da carta criada. | Alta |
| RF09 | O sistema deve permitir informar o nome da carta. | Alta |
| RF10 | O sistema deve permitir selecionar o tipo da carta. | Alta |
| RF11 | O sistema deve permitir inserir uma descrição para a carta. | Alta |
| RF12 | O sistema deve permitir definir atributos da carta. | Alta |
| RF13 | O sistema deve permitir selecionar a raridade da carta. | Média |
| RF14 | O sistema deve permitir upload de imagens para a carta. | Alta |
| RF15 | O sistema deve permitir selecionar tags para categorização. | Média |
| RF16 | O sistema deve permitir adicionar novas tags personalizadas. | Média |
| RF17 | O sistema deve permitir cancelar a criação da carta. | Média |
| RF18 | O sistema deve permitir salvar a carta criada. | Alta |
| RF19 | O sistema deve validar os campos obrigatórios antes do salvamento, impedindo o envio de formulários com campos obrigatórios vazios. | Alta |

*Tabela 2:* Requisitos Funcionais da Criação de Cartas.

---

## Tabela 3 — Requisitos Funcionais da Visualização das Cartas

| ID | Requisito | Prioridade |
|----|-----------|------------|
| RF20 | O sistema deve permitir buscar cartas pelo nome. | Alta |
| RF21 | O sistema deve permitir ordenar cartas por diferentes critérios, como data de criação e ordem alfabética. | Média |
| RF22 | O sistema deve exibir cartas em formato de amostra/listagem. | Alta |
| RF23 | O sistema deve exibir as cartas cadastradas do usuário. | Alta |
| RF24 | O sistema deve permitir busca de cartas pela barra de pesquisa. | Alta |

*Tabela 3:* Requisitos Funcionais da Visualização das Cartas.
